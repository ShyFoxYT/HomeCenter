## 🤔 What is HomeCenter?

**HomeCenter** is a dedicated Android application designed to upcycle your older or inexpensive Android tablets into beautiful, highly functional Smart Home control panels. 

Built exclusively to integrate with a **Home Assistant** server on your local network, HomeCenter provides a streamlined, distraction-free interface to control your home's lighting, scenes, and connected devices. 

> [!IMPORTANT]
> HomeCenter requires an active, discoverable Home Assistant server on your local network. 

> [!WARNING]
> The use of servers outside the local network is currently untested and not recommended!

> [!NOTE]
> The app interface is optimized for landscape viewing on Android Tablets with a screen size of **10.4 inches and larger**.

## ✨ Key Features

* **⚡ Auto-Discovery:** Instantly detects your local Home Assistant server—no manual IP hunting required.
* **🎨 Modern UI:** A sleek, intuitive, and responsive dashboard designed for tablet displays.
* **🎛️ Universal Support:** Control all your integrated Home Assistant devices, trigger scenes, and manage your home state.
* **📊 Fritz!Box Integration:** Exclusive network throughput display for Fritz!Box users *(Requires the latest Fritz!OS)*.

## 🚀 Installation and Setup
> [!CAUTION]
> **No releases yet!** This project has just started and is in early active development. There are currently no APKs or versions available for download. Check back soon for the first release!

HomeCenter is currently distributed directly via APK. A Google Play Store version is possible in the future, but not currently planned.

### Prerequisites
1. An Android tablet.
2. A running Home Assistant server on the same local network.

### Step-by-Step Guide
1. **Download:** Grab the latest `HomeCenter.apk` from the [Releases](../../releases) page.
2. **Install:** Install the APK on your tablet. *(Note: You may need to enable "Install from unknown sources" in your Android settings).*
3. **Personalize:** Open the app and pick a display username for your dashboard (this does not have to match your Home Assistant login).
4. **Localize:** Assign the tablet's physical location (e.g., "Living Room") or create a custom room name. *(Note: Room syncing across multiple tablets is planned for a future update!)*
5. **Connect:** 
   * Tap **Search Automatically** to find your Home Assistant server, OR select **Enter IP Yourself**.
   * Authenticate by pasting your Token, or use the built-in **QR Code Scanner** for a rapid login.
6. **Customize:** Edit your new dashboard to your liking!
